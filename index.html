Glossary — easy ways to remember it

The core idea: your project moves through three "rooms" as you work.

Working Directory
Your desk. Where you're actually editing files.
Staging Area
A gift box. You choose which edits go in before you seal it.
Repository / commit
A photograph. A permanent snapshot you can always come back to.
Branch
A parallel notebook. Try new ideas without touching the original.
HEAD
A "you are here" pin — shows which branch/commit you're standing on.
Merge
Combining two notebooks' ideas back into one.

Reference-only commands (not simulated here — try them for real once you're comfortable!):

git stash
Shove your mess in a drawer for later
git rebase -i
Rewrite/squash your photo album
git cherry-pick
Copy one photo onto another timeline
git reset --hard
Throw away all unsaved edits
git remote / push / pull
Sync your notebook with a shared one online
git reflog
The safety net that remembers everything, even mistakes
